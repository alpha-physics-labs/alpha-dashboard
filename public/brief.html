02Where the physics is

The model never invents physics. It only corrects it.

INPUT

Physical quantities

132 measurable element properties: electronegativity, atomic volume, valence electrons, melting point. No black box.

LEARNING

A law, then a correction

A scaling law answers first. The network learns only the gap between law and reality, and is penalised if it starts believing something physically absurd.

OUTPUT

Exact equations

Only two numbers are learned. The rest is closed-form classical physics.

log G = c₀ + a₁·log(VED) + a₂·log(COH) − b₁·ionicity − a₃·log(rcov)
E = 9KG/(3K+G)   ν = (3K−2G)/2(3K+G)   v = √(G/ρ)   Z = ρ·v

Proof in one test: type copper. We return Young's modulus 111 GPa and Poisson's ratio 0.358. Textbook says 117 and 0.34. Neither was ever trained on — both came from two predictions and equations Poisson wrote in the 1820s.

06Next

Structure-aware models Needs one GPU

We already hold 10,987 crystal structures whose 3D arrangement we currently discard, keeping only the formula. A graph network on them is our biggest available accuracy gain — and it answers the criticism that a formula cannot tell one crystal phase from another.

Impact & ballistic heads Needs partner data

Impact energy absorption, then V50 and back face deformation against areal density. We start from an established analytical armor model as the physics prior and learn the correction from flat plate tests — the recipe already proven on stiffness.
